- **animation-principles**: Three concurrent motion layers and beat quantization can create decoration; use only when they explain actual content.; Do not move narration or meaningful state changes merely to fit a beat.
- **motion-art-direction**: One personality/one wow and low-energy opening are heuristics; latest user wants strong hook, varied meaningful scenes and real footage with useful simulation.; Consistency must not become repetitive shots.
